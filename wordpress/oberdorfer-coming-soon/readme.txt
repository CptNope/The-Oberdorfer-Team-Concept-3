=== The Oberdorfer Team (Coming Soon) ===

A one-page block theme that holds oberdorferteam.com until the full site launches.

* Every route shows the same page. The home page returns 200 and is indexable; every other
  URL returns 404 with the same content, so search engines only index the home page.
* Text is editable in Appearance > Editor > Patterns > Coming soon (or Templates).
* Fonts load from Google Fonts on this page only; the full theme self-hosts them.
* No forms: there is no privacy policy or team email yet. Calls and texts go to 406-250-7620.
* Source: wordpress/oberdorfer-coming-soon/ in the project repository. Rebuild the zip with
  python3 tools/build_coming_soon.py. Setup steps: docs/coming-soon-launch.md.

Fonts: Cormorant Garamond and Manrope, SIL Open Font License 1.1.
