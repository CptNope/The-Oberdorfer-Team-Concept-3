# WordPress build v0.10.13

**JAT Search Intel now runs the site's search output.**

Search Intel 3.8.19 (`wordpress/jat-search-intel.zip`) prints the titles, descriptions, canonicals, social tags, the JSON-LD graph, the XML sitemap (`/sitemap.xml`) and `/llms.txt`. ot-core stops printing its own and feeds Search Intel what only it knows, so search engines see the same information as before:

- **Schema:** the team as a RealEstateAgent (office, phone, Massachusetts, REWAP Brokerage LLC) on Search Intel's Organization; each agent's ProfilePage and Person, the joint page's AboutPage, each town guide's City, listings, the market Dataset and the guide index; and the site's own breadcrumb trail. Pages, guides and profiles no longer name the WordPress account that saved them as their author.
- **Titles and descriptions:** every page's tested search title and description is copied once into Search Intel's box, where the team now edits them.
- **Hidden town guides** are marked noindex, so they stay out of the sitemap.
- **/llms.txt** keeps the curated summary (sourced facts, the people, every page and guide).
- **Agents' listings pages and the guide index** keep their own title, description and canonical, which Search Intel cannot work out.
- **Privacy:** Search Intel adds no cookies or tracking. Its log of requests for missing pages (address, linking page, browser, a code made from the IP address) is deleted 90 days after the last request; the privacy policy says so.

Search Intel settings: FAQ, HowTo and Speakable schema, image alt text and the RSS footer stay off.
