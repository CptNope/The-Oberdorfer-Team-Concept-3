# WordPress build v0.10.14

**Site security, and the privacy policy to match.**

JAT Site Shield 1.1.2 (from WordPress.org) now protects the site: login lockouts, two-factor for administrators, XML-RPC and username scanning blocked, the file editor off, PHP refused in uploads (tested), security headers, an activity log kept 90 days, alerts to the site admin email and a daily file integrity check. The login page stays at its usual address for now.

- **Privacy policy:** a "Site security" paragraph: sign-in attempts and requests that look like attacks are recorded with the IP address and browser, and deleted after 90 days. The live Privacy page also gets the "Missing pages" paragraph from v0.10.13.
- **WordPress core:** re-installed 7.1.4 after the file check found 26 AI-client files whose names the host's installer had cut short; the 21 cut-off leftovers were deleted over SFTP.
