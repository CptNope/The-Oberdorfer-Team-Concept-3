# WordPress build v0.10.17

**JAT Search Intel 3.8.22, with the fixes found on this site.**

`wordpress/jat-search-intel.zip` is now 3.8.22 (CptNope/JAT-Search-Intel#65):

- Decorative images (an empty `alt=""`) stay decorative; the alt-text feature only fills in a missing alt.
- Canonicals follow WordPress's own canonical URL, so views beneath a post (an agent's listings page) and split posts point at themselves.
- Custom post-type archives (the guide index) get a canonical and a description.
- robots.txt names the JSON schema map in a comment instead of a `Sitemap:` line.
- New filters for canonicals, descriptions and extra sitemap URLs.

ot-core uses the new hooks: the guide index's description goes through Search Intel (no second set of tags), and agents' listings pages that have listings are added to the agents' sitemap. With an older Search Intel the earlier fallbacks still apply.
