# WordPress build v0.10.7

**Online booking on agent profiles, hidden until it is set up.**

- Agent profiles get a "Book a call" section (before "Contact") and a "Book a call" button in the hero, from the JAT Calendar Sync plugin (2.1+, its People feature: each agent books into their own Google Calendar).
- Both render nothing until `jatcs_host_ready()` is true for that agent: their Google Calendar is connected and they have a visible appointment type. Without the plugin, nothing changes.
- The agent is matched by slug (People slug = profile slug, for example `kaitlyn-oberdorfer`); the new Agent details field "Online booking" can name another.
- Before turning it on for an agent: update the privacy policy and the accessibility statement, then purge the caches.
