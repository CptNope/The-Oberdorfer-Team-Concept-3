First pre-release of the production WordPress build for oberdorferteam.com: the **Oberdorfer block theme** and the **Oberdorfer Core** plugin. For a staging site, not the live domain yet.

## Install (WordPress 7.1+, PHP 8.3+)
1. **Plugins > Add New > Upload Plugin:** upload `ot-core.zip`, then activate.
2. **Appearance > Themes > Add New > Upload Theme:** upload `oberdorfer.zip`, then activate.
3. **Tools > Import Oberdorfer content > Import now.** This creates the 33 town guides, 28 neighborhood guides, Brandon's, Kaitlyn's and the team's profiles, the Worcester office and the site's pages, sets the front page and the Journal page, and switches permalinks to "Post name". Running it again updates the same items in place.
4. On staging, keep **Settings > Reading > Discourage search engines** checked. Canonical URLs already point at oberdorferteam.com.

## What's in it
- **Theme:** 17 templates, header and footer, 49 patterns named after the FSE canvas boards, `theme.json` generated from the design tokens. Every block passes WordPress 7.1's block validator.
- **Oberdorfer Core:** community guides, agents and offices as post types (a neighborhood is a child of its city: `/communities/worcester/tatnuck/`), registered fields, 11 server-rendered blocks, titles, meta descriptions, canonicals, JSON-LD, sitemap adjustments, `/llms.txt` and the importer. Content lives here, not in the theme, so a redesign never loses it.

## Tested
WordPress 7.1.3 installed from these zips: every page type renders (missing pages return 404) with no PHP notices; guides and profiles match the prototype side by side at desktop width and fit a phone without sideways scrolling.

## Not yet
- Forms validate and show a confirmation but **send nothing** until the `ot-leads` plugin.
- Listings show a placeholder until the IDX provider is chosen.
- Journal articles are not imported; guide data is edited as data until a field editor (`ot-blocks`).
- Fonts load from Google Fonts (self-host before launch).
