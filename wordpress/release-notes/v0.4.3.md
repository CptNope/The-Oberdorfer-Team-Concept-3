Fixes the house drawings, and makes sure style fixes reach visitors. Pre-release for staging.

- **Cache busting:** the theme's CSS and JavaScript are now tagged with the theme version. Since 0.1.0 they had a fixed tag, so caches on staging kept serving the old stylesheet and the 0.4.2 drawing fix did not appear.

- **Community cards** (Communities page, home page): the drawing is now centered in the space above the town name. It was pinned to the top-left corner because the cards' photo rule stretched it from the corner.
- **Listing pages:** a listing without a photo shows the whole drawing, centered. In the wide gallery frame it used to grow taller than the frame and lose its bottom.

The fix is in the design system's `components.css`, so the prototype site gets it too.
