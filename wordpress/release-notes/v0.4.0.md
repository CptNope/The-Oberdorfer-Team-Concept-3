Makes the rest of the site editable by clicking a block. Pre-release for staging.

## The main pages
Home, Buy, Sell, Market, Team, Join and Contact are now edited in the page itself: **Pages > (the page)**, click any heading, paragraph, button or photo, type, then **Save**.
- The figure tiles, the buying and selling steps, the seller checklist (a table), the contact lines and the home cover photo are normal blocks now, not code.
- What stays code: the search bar and other forms, the house drawings and icons, and the tab controls on Contact.

## Shared parts: Appearance > Editor
- **Header** (Patterns > Header): the navigation links are ordinary text links and the phone is a button. The mobile menu follows the navigation automatically.
- **Footer** (Patterns > Footer): already text and lists; the REWAP plate stays as supplied.
- **Agent profiles** (Templates > Agent profile): "About", "How {first name} can help", client stories and the contact text are blocks shared by both profiles. Write `{first name}` where the agent's first name goes.

## Unchanged
- Guide research (facts, prices, commute, sources) stays protected so every figure keeps its source.
- Each profile's questions and message form are still built from the profile.

## Upgrade from 0.3.0
1. Upload both zips again ("Replace current with uploaded"), then purge Breeze and Cloudflare.
2. Open the dashboard once: pages with an empty body get their sections automatically. (Or run Tools > Import Oberdorfer content.)
3. If anyone edited the header, footer, page or agent templates in Appearance > Editor, reset them there so the new versions show.
