# WordPress build v0.10.24

**SEO and speed pass.** An audit of all 77 pages in the sitemap found titles, descriptions, headings, canonicals, schema and alt text in order (PageSpeed mobile: SEO 100, Accessibility 100, Best Practices 100, Performance 86). This release takes on what it did find.

- **Responsive photos:** theme photos now carry a srcset of 640 and 960 pixel copies, sizes, and width and height. On a phone the home page's main photo drops from about 90 KB to about 40 KB.
- **One stylesheet:** the five theme stylesheets load as one minified file instead of five render-blocking requests.
- **Turnstile on demand:** the spam check's script (about 27 KB) loads only when a form is near the screen or in use.
- **No redirect in an internal link:** agent profiles link straight to the joint page.
- With JAT Search Intel 3.8.31, the home page is listed once in the sitemap (it was listed twice).
