Adds a switch for listings (IDX), so the site can run without them until the IDX provider is chosen, and go live with them later in one step. Pre-release for staging.

## What's new
**Settings > Listings (IDX)** (in Oberdorfer Core). Off by default. While off, the site leaves out everything that searches or shows homes for sale:
- the search bar on the home page cover
- the home page's "Featured homes" section
- the search icon in the header
- the "Search homes" label under Buy in the mobile menu
- the property search section of the Buy page

They are removed from the page on the server (not just hidden), and nothing is deleted: the Buy page keeps its buying guide, and ticking the box brings every piece back. While listings are off, an admin bar reminder reads "Listings: off".

The same screen has fields for the IDX provider's shortcodes (Buy page search, home page featured homes). To go live later: install the provider's plugin, paste its shortcodes, tick **Show listings**, save, then purge Breeze and Cloudflare. `define( 'OT_IDX_ENABLED', true );` in wp-config.php overrides the checkbox if you'd rather control it per server.

## Upgrade from 0.1.1
Upload both zips again (Plugins and Themes > Upload, "Replace current with uploaded"). No re-import is needed. Listings switch off as soon as the new plugin is active.
