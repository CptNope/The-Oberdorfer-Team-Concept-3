# WordPress build v0.10.15

**All of the site's email now goes through Brevo.**

Only the lead plugin's own email used Brevo; everything else that WordPress sends (JAT Site Shield's security alerts, JAT Calendar Sync's booking confirmations and reminders, password resets, WordPress notices) went through the server's PHP mail, which is not authenticated for oberdorferteam.com, so it was lost or filtered as spam. The Site Shield test alert never arrived.

ot-leads now hands every `wp_mail()` to Brevo once its key is set: from the team's verified address (the sending plugin's name kept, its own address as Reply-To), HTML or plain text, Cc, Bcc and attachments. If Brevo refuses a message, WordPress's own mail is tried, so nothing is worse off than before.
