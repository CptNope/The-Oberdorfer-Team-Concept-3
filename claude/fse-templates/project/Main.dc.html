A full-site-editing theme built from the static prototype. Every section below is a block pattern made of core blocks and the theme's own ot/* blocks, so editors arrange pages in the Site Editor without touching code.

Every template opens with parts/header.html and closes with parts/footer.html. index.html, 404.html and search.html are still needed for a complete theme; they are not designed yet.

Content models

Custom post types: Agents, Communities, Offices, Testimonials, Publications. The journal uses standard posts.

Listings come only from the authorized IDX/MLS feed. The provider is not chosen, so the Buy and listing templates show where its blocks will sit.
