Mobile menu

A full-screen navy sheet that opens with a top-down clip reveal. Links are set at 30px Cormorant, so the menu reads like a table of contents rather than a list of buttons.

  • The toggle has aria-expanded. Escape closes the menu and returns focus to the toggle.
  • Content behind the menu is made inert while it is open.
  • The call button stays in the thumb zone at the bottom.
  • Under reduced motion, the menu appears without the wipe.
